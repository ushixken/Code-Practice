# Stylesheet structure

```
css/
├─ app.css      Roadmap and Problems layout, editor, lesson, and navigation styles
└─ planner.css  Code Planner canvas, nodes, templates, and planner controls
```

If a Roadmap or Problems screen looks wrong, start in `app.css`. If a node, arrow, template, or planner panel looks wrong, start in `planner.css`.
